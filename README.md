# OneClick-Classwork (詐欺サイト体験シミュレーター)

## 開発の背景
このツールは、家庭科の授業における「情報モラル教育」の一環として開発しました。
ワンクリック詐欺の恐ろしさを「ストーリー動画」として制作・発表する際の教材として、実際にブラウザで動作するリアルな詐欺体験を提供することを目的としています。

## 本ツールの学習ポイント
- **検索広告の罠**: 検索結果の一番上にある「スポンサー広告」が必ずしも安全ではないことを学びます。
- **不安を煽る演出**: 突然の警告音、フラッシュする画面、カウントダウンタイマーなど、冷静な判断を失わせる詐欺の手口を体感します。
- **個人情報の偽装表示**: 端末情報やIPアドレスが「抜き取られた」ように見せる演出により、なぜ多くの人が騙されてしまうのかを理解します。

## 機能
- **Google検索シミュレート**: リアルなUIで検索体験を再現。
- **自動情報生成**: 実行時の日時、ランダムなIPアドレス、ブラウザ情報を動的に表示。
- **警告音 (Web Audio API)**: ユーザーの不安を誘うビープ音を再生。

## 教育利用上の注意
- 本ツールは**フィクション**であり、実際に金銭を請求したり、個人情報を収集したりすることはありません。
- 授業外で他者を驚かせる目的で使用しないでください。
- 画面上の電話番号は架空のものです。

## 使い方
1. `index.html` をブラウザで開く。
2. 検索結果の一番上にある「V-Bucks 10000円分を無料提供！」という広告をクリック。
3. 詐欺画面が表示されます。
